# 剪贴板抽屉柜 (Clipboard Drawer) 设计文档

日期：2026-10-08
状态：已确认

## 1. 概述

一个跨平台（macOS / Windows / Linux）桌面应用，以"抽屉柜"形式展示剪贴板历史：左侧为最近 7 个日期对应的抽屉，点击某个抽屉，右侧展示该日期复制的所有文本。应用常驻系统托盘，通过全局快捷键唤起。

## 2. 需求确认

| 决策项 | 结论 |
|---|---|
| 平台 | mac / Windows / Linux 三平台兼容 |
| 唤起方式 | 托盘常驻 + 全局快捷键（默认 Cmd/Ctrl+Shift+V） |
| 界面风格 | 左侧竖排抽屉（7 个日期抽屉 + 右侧内容面板） |
| 条目操作 | 点击重新复制、删除条目、搜索、自动去重 |
| 数据保留 | 全部历史永久保留；界面只展示最近 7 天，更早的通过搜索找到 |
| 技术框架 | Electron |

## 3. 架构

```
┌────────────────────────────────────────────┐
│ Electron 主进程                            │
│  · 托盘图标 / 菜单                           │
│  · 全局快捷键（globalShortcut）              │
│  · 剪贴板监听（clipboard.readText 轮询）      │
│  · 数据库读写（better-sqlite3）              │
│  · 窗口生命周期（显示/隐藏/定位）             │
└──────────────┬─────────────────────────────┘
               │ IPC
┌──────────────▼─────────────────────────────┐
│ 渲染进程（单个窗口，无前端框架，原生 HTML/CSS）│
│  · 抽屉柜 UI                               │
│  · 搜索、删除、复制交互                     │
└────────────────────────────────────────────┘
```

- **主进程**：托盘、快捷键、剪贴板监听、SQLite 持久化、窗口管理。
- **渲染进程**：纯原生 HTML/CSS/JS（不引入 React/Vue，保持轻量），通过 IPC 请求数据。
- **通信协议**（IPC channels）：
  - `clipboard:listByDay(date)` → 某天的条目列表
  - `clipboard:search(keyword)` → 跨全部历史搜索，按日期分组返回
  - `clipboard:delete(id)` / `clipboard:clearDay(date)`
  - `clipboard:copy(id)` → 主进程写回系统剪贴板并隐藏窗口
  - `window:hide`

## 4. 数据存储

- **SQLite**（`better-sqlite3`），文件位于 Electron `userData` 目录下 `clipboard.db`。
- 表结构：

```sql
CREATE TABLE IF NOT EXISTS clips (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  text TEXT NOT NULL,
  created_at INTEGER NOT NULL  -- 毫秒时间戳
);
CREATE INDEX IF NOT EXISTS idx_created_at ON clips(created_at);
```

- **自动去重**：同一天内 trim 后内容完全相同的文本不重复插入（插入前查询当天是否已存在相同 text）。
- **保留策略**：永久保留，不自动清理。
- **存储上限**：单条文本超过 500 字符正常存储，仅列表显示时截断。

## 5. UI 设计

### 布局（左侧竖排抽屉）

```
┌──────────────┬────────────────────────────┐
│  🔍 搜索框    │   2026-10-08（今天）  12条  │
│──────────────│  ┌────────────────────────┐ │
│ ▤ 今天       │  │ 09:23 这是一段复制的… × │ │
│ ▤ 昨天       │  ├────────────────────────┤ │
│ ▤ 周三 10/7  │  │ 10:41 https://examp… × │ │
│▶▤ 周二 10/6  │  ├────────────────────────┤ │
│ ▤ 周一 10/5  │  │ 14:07 另一段文本内容… × │ │
│ ▤ 周日 10/4  │  └────────────────────────┘ │
│ ▤ 周六 10/3  │                            │
│──────────────│                            │
│ 清空当天      │                            │
└──────────────┴────────────────────────────┘
```

### 交互规则

- 左侧固定 7 个抽屉：今天、昨天、周几+日期（如"周三 10/7"），每个抽屉显示当天条数；选中高亮。
- 右侧列表按时间倒序展示选中日期的全部文本；单行截断，悬停 tooltip 显示完整内容。
- **点击条目** → 复制回系统剪贴板 → 隐藏窗口。
- 条目右侧 `×` → 删除该条；底部"清空当天"→ 删除该天全部。
- **搜索框**：输入即跨全部历史过滤（不限 7 天），结果按日期分组展示；聚焦搜索框可通过快捷键直接开始输入。
- 主题：深色/浅色跟随系统。
- 窗口行为：快捷键唤起时定位到鼠标所在屏幕中央；失去焦点自动隐藏；Esc 关闭。
- 托盘菜单：显示窗口、开机自启开关、退出。开机自启默认关闭。

## 6. 错误处理

| 场景 | 处理 |
|---|---|
| 剪贴板读取失败 | 静默跳过该次轮询，记录日志，不影响主程序 |
| 数据库文件损坏 | 启动时校验失败 → 备份为 `clipboard.db.bak` 并重建空库 |
| 去重判断 | 按 trim 后文本精确匹配当天记录 |
| 插入失败 | 静默忽略该条，不弹出错误 |

## 7. 测试策略

- 数据层单元测试：插入、去重、按天查询、搜索、删除、清空。
- 主进程逻辑测试：剪贴板变化检测（mock 剪贴板）、日期分组计算。
- 手动验证项：快捷键唤起/隐藏、点击复制、三平台打包运行。
