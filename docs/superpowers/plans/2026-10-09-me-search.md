# Me-Search（强化字面搜索）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把主窗口搜索框升级为 Me-Search 引擎——模糊子序列 + 拼音搜索 + 评分排序平铺呈现，定位从"剪贴板管理"升级为"搜索过去的自己"。

**Architecture:** 拼音写时物化进 SQLite 新列（pinyin-pro 生成，仅 CJK 行），查询走两阶段：SQL 子串快路径（text + pinyin 双通道）→ 候选不足时主进程对最近 5000 条文本行跑子序列模糊兜底；纯函数打分排序后透传 IPC，渲染层平铺 + 高亮 + 徽章。渲染层防抖 150ms。

**Tech Stack:** Electron 33、better-sqlite3、pinyin-pro（纯 JS 拼音库，仅主进程使用）。

**Spec:** `docs/superpowers/specs/2026-10-09-me-search-design.md`

**分支基线:** 本计划基于 v3 分支 `feature/snippets-privacy`（60/60 测试）。v4 分支 `feature/me-search` 从它切出；v3 合并回 main 后本分支 rebase/改指 main。

## 背景：执行者需要知道的现有结构

- **store.js**（`src/main/store.js`）：`ClipStore` 类。构造函数里 `CREATE TABLE IF NOT EXISTS clips`（10 列）+ `migrate()`（PRAGMA table_info 门控 ALTER，v3 教训：**CREATE 语句必须同步包含新列**）。`insert(text, now)` 走 `insertStmt`（`INSERT INTO clips (text, created_at) VALUES (?, ?)`）；`search(keyword)` 走 `searchStmt`（`type='text' AND text LIKE ? ESCAPE '\'` LIMIT 200，created_at DESC）。行 SELECT 统一 10 列顺序：`id, text, created_at, type, image_path, width, height, pinned, trigger_word, group_name`。
- **ipc.js**：`clipboard:search` handler = `store.search(keyword).map(withMeta)`；`withMeta = (row) => withSecret(withThumb(row))`，spread 透传，新字段自动随行返回。
- **渲染层**（`src/renderer/app.js`）：主窗口逻辑在 `else` 块内。`doSearch()` 当前按日期分组渲染（Map 收敛 + `.search-group` 头）；`state.items` 扁平顺序与 DOM 一致（Enter 复制依赖）；搜索输入监听在 else 块底部。
- **测试**：`npm test` = `cross-env ELECTRON_RUN_AS_NODE=1 electron --test tests/`（**绝不 plain node**）；单文件：`npx cross-env ELECTRON_RUN_AS_NODE=1 node_modules/.bin/electron --test tests/<file>`。基线 60/60。
- **渲染层无自动化测试**（惯例）：门 = `node --check` + 全量不回归 + 冒烟。
- **条目行形状**（search 返回）：10 列 + `thumb` + `secret`（withMeta 后）。v4 起再加 `score, match_kind, match_pos, match_len`。

- [ ] **Step 2: 实现 scoreRow（src/main/store.js，纯函数，module.exports 追加）**

```js
// Me-Search 评分：substring(100+位置加成) > pinyin(90+位置加成) > fuzzy(80−跨度惩罚)；无命中 null
function scoreRow(r, kw) {
  const text = r.text.toLowerCase();
  const pos = text.indexOf(kw);
  if (pos >= 0) {
    return { score: 100 + Math.max(0, 50 - pos), match_kind: 'substring', match_pos: pos, match_len: kw.length };
  }
  if (r.pinyin) {
    const ppos = r.pinyin.indexOf(kw);
    if (ppos >= 0) {
      return { score: 90 + Math.max(0, 50 - ppos), match_kind: 'pinyin', match_pos: null, match_len: null };
    }
  }
  let ti = 0; let first = -1; let last = -1;
  for (const ch of kw) {
    const found = text.indexOf(ch, ti);
    if (found < 0) return null;
    if (first < 0) first = found;
    last = found;
    ti = found + 1;
  }
  const span = last - first + 1;
  return { score: Math.max(1, 80 - (span - kw.length) * 2), match_kind: 'fuzzy', match_pos: null, match_len: null };
}
```

search() 整体替换：

```js
  // Me-Search：SQL 子串快路径（text + 罗马查询时的 pinyin）→ 候选 <20 且查询 ≥3 字符 → 最近 5000 行子序列兜底
  // 评分排序（substring > pinyin > fuzzy，同分新者先），返回 top 50，行附加 score/match_kind/match_pos/match_len
  search(keyword) {
    const kw = String(keyword).trim();
    if (!kw) return [];
    const lower = kw.toLowerCase();
    const escaped = lower.replace(/[\\%_]/g, (ch) => '\\' + ch);

    const byId = new Map();
    for (const r of this.searchTextStmt.all(`%${escaped}%`)) byId.set(r.id, r);
    if (/^[a-z0-9]+$/.test(lower)) {
      for (const r of this.searchPinyinStmt.all(`%${escaped}%`)) byId.set(r.id, r);
    }

    const scored = [];
    for (const r of byId.values()) {
      const s = scoreRow(r, lower);
      if (s) scored.push({ ...r, ...s });
    }

    if (scored.length < 20 && lower.length >= 3) {
      for (const r of this.fuzzyScanStmt.all()) {
        if (byId.has(r.id)) continue;
        const s = scoreRow(r, lower);
        if (s && s.match_kind === 'fuzzy') scored.push({ ...r, ...s });
      }
    }

    scored.sort((a, b) => b.score - a.score || b.created_at - a.created_at || b.id - a.id);
    return scored.slice(0, 50);
  }
```
